## 🔧 V0.4核心改进

### 1. 简化模型架构 ⭐⭐⭐⭐⭐

```python
# config.py
BASE_CHANNELS = 48  # 从64降到48
DEPTH = 4           # 从5降到4

# 预期效果
参数量: 31.4M → 8.5M (-73%)
参数/slice: 11,765 → 3,181 (更合理)
最小分辨率: 14×14 → 28×28 (空间细节提升4倍)
```

**理由**:
- 减少过拟合主因
- Depth=4对WMH更适合（28×28保留更多空间信息）
- 7通道输入已提供高级特征，不需要超大模型

---

### 2. 强化数据增强 ⭐⭐⭐⭐

```python
# dataset.py - get_train_transform()
A.VerticalFlip(p=0.7)          # 提高到70% (从50%)
A.Rotate(limit=25, p=0.8)       # 提高到±25°, 80% (从±20°, 70%)
A.ElasticTransform(alpha=40, sigma=8, p=0.4)  # 提高到α=40, 40% (从α=30, 20%)
A.GridDistortion(p=0.4)         # 提高到40% (从30%)
A.RandomBrightnessContrast(brightness_limit=0.12, p=0.8)  # ±12%, 80%
A.RandomGamma(gamma_limit=(88, 112), p=0.6)  # 88-112, 60%
# 考虑添加 GaussNoise(var_limit=0.002, p=0.2)  # 轻微噪声20%
```

**理由**:
- 小模型需要更多数据多样性
- 适度增强不会破坏WMH结构
- 提高泛化能力

---

### 3. 添加Dropout正则化 ⭐⭐⭐

```python
# model.py - ConvBlock
class ConvBlock(nn.Module):
    def __init__(self, in_channels, out_channels, dropout=0.15):
        super().__init__()
        self.conv = nn.Sequential(
            nn.Conv2d(in_channels, out_channels, 3, padding=1, bias=False),
            nn.BatchNorm2d(out_channels),
            nn.ReLU(inplace=True),
            nn.Dropout2d(dropout),  # 添加
            nn.Conv2d(out_channels, out_channels, 3, padding=1, bias=False),
            nn.BatchNorm2d(out_channels),
            nn.ReLU(inplace=True),
        )
```

**理由**:
- 进一步降低过拟合
- Dropout=0.15较保守，不会过度影响性能

---

### 4. 优化训练策略 ⭐⭐⭐⭐

```python
# train.py
EPOCHS = 200  # 从150提高（小模型需要更多epoch）
EARLY_STOP_PATIENCE = 20  # 从50降低（更激进早停）
EARLY_STOP_MIN_DELTA = 0.002  # 更严格
```

**理由**:
- 小模型收敛慢，需要更多epoch
- 更激进早停避免过拟合
- V0.3在133 epoch最佳，150 epoch反而下降

## ⚠️ 风险与mitigation

### 风险1: 模型容量不足
**迹象**: Train Dice < 0.88
**应对**: 
- 尝试base=56或base=64
- 但保持depth=4

### 风险2: 收敛变慢
**迹象**: 50 epoch后Val Dice仍< 0.75
**应对**:
- 提高学习率到2e-4
- 延长训练到250 epoch

### 风险3: 小WMH检测变差
**迹象**: Sensitivity下降
**应对**:
- 适度降低Dropout (0.15 → 0.1)
- 检查Focal Tversky Loss参数
