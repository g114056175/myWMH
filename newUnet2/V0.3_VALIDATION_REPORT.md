## 🎯 V0.3 最终配置

### 输入通道 (7通道)
```python
Ch0: CLAHE(FLAIR[t-1])  # 2.5D前层
Ch1: CLAHE(FLAIR[t])    # 当前层
Ch2: CLAHE(FLAIR[t+1])  # 2.5D后层
```
