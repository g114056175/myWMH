## 🎯 最终架构决策

### 输入通道：7通道

```python
Ch0: FLAIR[t-1] - CLAHE    # 2.5D前层，CLAHE增强
Ch1: FLAIR[t]   - CLAHE    # 当前层，CLAHE增强
Ch2: FLAIR[t+1] - CLAHE    # 2.5D后层，CLAHE增强
Ch3: T1[t]      - Raw      # 保留T1多模态信息
Ch4: HighPass[t] (σ=2.0)   # 边缘检测 (V0.2权重最高17.77%)
Ch5: Asymmetry             # 左右不对称特征 (5.46x对比度)
Ch6: Spatial Atlas         # 空间先验图谱 (6.09x对比度, 87%覆盖)
```

**核心设计理念**:
- ✅ 用CLAHE替代Raw FLAIR → 统一2.5D增强，减少冗余
- ✅ 保留T1 → 唯一非FLAIR模态，深层特征可能利用
- ✅ 新增2个验证有效的全局特征

### 优化2: Dual Attention ⭐⭐⭐⭐⭐

**改动**: Spatial Attention → Spatial + Channel Attention  
**预期**: +2-3% Dice  
**实现**:
```python
class DualAttentionGate(nn.Module):
    def __init__(self, channels):
        self.channel_attention = ChannelAttention(channels)
        self.spatial_attention = SpatialAttention()
    
    def forward(self, g, x):
        x = self.channel_attention(x)    # 通道：什么特征重要
        x = self.spatial_attention(g, x) # 空间：哪里有特征
        return x
```

**理由**:
- 帮助模型选择重要通道（7通道中哪些更重要）
- 与Spatial Atlas配合，双重空间建模
- 低成本 (VRAM +5%, 训练时间 +5-10%)

---

### 优化3: CosineAnnealingWarmRestarts ⭐⭐⭐⭐⭐

**改动**: ReduceLROnPlateau → CosineAnnealingWarmRestarts  
**预期**: +1-2% Dice  
**理由**: 修复V0.2的LR降到0的bug

```python
scheduler = torch.optim.lr_scheduler.CosineAnnealingWarmRestarts(
    optimizer,
    T_0=50,        # 第一次重启周期
    T_mult=1,      # 周期倍增
    eta_min=1e-6   # 最小LR，不会降到0
)
```
